# 🏥 Hospital Login Page – Medical Billing System online

A secure and user-friendly Hospital Login Page developed as part of the **Medical Billing System**. This application provides authenticated access for hospital staff to manage patients, doctors, billing, and reports in an offline environment.

---

## 📖 Overview

The Hospital Login Page is the entry point of the Medical Billing System. It verifies user credentials and provides secure access to different modules of the application. The project is developed using **Python, Flask, SQLite, HTML, CSS, and Bootstrap**.

---

## ✨ Features

- 🔐 Secure User Login
- 👨‍⚕️ Admin Authentication
- 👩‍💼 Receptionist Login
- 👤 Patient Registration
- 🩺 Doctor Management
- 💳 Medical Billing
- 🧾 Invoice Generation & Printing
- 📊 Reports Dashboard
- 🚪 Logout Functionality

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/username/MedicalBillingSystem.git
```

### Navigate to Project Folder

```bash
cd MedicalBillingSystem
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

---

## 🚀 Usage

1. Launch the application.
2. Open the login page.
3. Enter a valid username and password.
4. Click **Login**.
5. Access the Hospital Dashboard.
6. Manage patients, doctors, billing, invoices, and reports.
